# Jianying Capability Boundary

The external `jianying-editor-skill` is an execution dependency discovered from
the configured local path. The project records its version and capability
fingerprint for every Run.

The Agent may select a semantic edit intent and an approved style profile. The
Registry and deterministic compiler select the actual native transition, animation,
subtitle, sticker, and track representation.

The Agent must not emit raw Jianying effect IDs, microsecond keyframes, or draft
JSON. The Jianying adapter receives a compiled blueprint and returns a draft
manifest. The current supported delivery is an editable draft; automatic export is
only reported when the installed editor and exporter have been verified together.
